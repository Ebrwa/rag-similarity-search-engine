# Similarity Search Engine

A semantic similarity search engine built using LangChain, HuggingFace Embeddings, and FAISS.

## Features
- Loads human rights documents from URLs.
- Splits documents into text chunks.
- Generates embeddings using HuggingFace.
- Stores vectors in FAISS.
- Retrieves the most relevant results using semantic similarity search.

## Technologies
- Python
- LangChain
- HuggingFace Embeddings
- FAISS
- BeautifulSoup
- Requests

## Run

```bash
pip install -r requirements.txt
python main.py
```
